# Отчёт о реализованных функциях  
**Проект:** Финансовый планировщик (FinPlanner)  
**Дата:** 27 марта 2026 г.

Ниже представлен перечень user stories, полностью реализованных в текущей версии приложения. Для каждой указан приоритет согласно исходной спецификации. Отчёт сохраняет структуру и формулировки оригинального документа.

---

## User Stories (реализованные)

### Роль: Пользователь

#### 1. Учётная запись и аутентификация

| ID | User Story | Приоритет |
|----|------------|-----------|
| US‑01 | **Как пользователь, я хочу зарегистрироваться в системе, указав email и пароль, чтобы получить личный кабинет.** | Must have |
| US‑02 | **Как пользователь, я хочу входить в систему с помощью email и пароля, чтобы иметь доступ к своим данным.** | Must have |

**Реализованные критерии приемки:**
- Поля email и пароль валидируются (email уникален, пароль не менее 8 символов).
- После регистрации пользователь перенаправляется на страницу входа, после входа — на дашборд.
- Сессия сохраняется с использованием JWT, хранящегося в HttpOnly cookie, при перезагрузке страницы пользователь остаётся авторизованным.

---

#### 2. Управление категориями

| ID | User Story | Приоритет |
|----|------------|-----------|
| US‑04-1 | **Как пользователь, я хочу назначать категории расходов, чтобы классифицировать транзакции под свои нужды.** | Must have |
| US‑04-2 | **Как пользователь, я хочу создавать собственные категории** | Must have |
| US‑04-3 | **Как пользователь, я хочу редактировать категории** | Must have |
| US‑04-4 | **Как пользователь, я хочу удалять категории** | Must have |
| US‑05 | **Как пользователь, я хочу видеть список всех моих категорий с возможностью быстрого выбора при добавлении транзакции.** | Must have |

**Реализованные критерии приемки:**
- Категории имеют тип (доход/расход), имя и принадлежность пользователю.
- Пользователь может создавать собственные категории, редактировать их название, удалять (если на них нет транзакций).
- Системные категории (предустановленные) доступны всем, но не могут быть изменены или удалены пользователем.
- Список категорий доступен на отдельной странице и используется в выпадающих списках при добавлении транзакций.

---

#### 3. Добавление транзакций (доходы/расходы)

| ID | User Story | Приоритет |
|----|------------|-----------|
| US‑06 | **Как пользователь, я хочу вручную добавлять доходы и расходы с указанием суммы, даты, категории и комментария, чтобы вести точный учёт.** | Must have |
| US‑07 | **Как пользователь, я хочу редактировать и удалять ранее добавленные транзакции, чтобы исправлять ошибки.** | Must have |

**Реализованные критерии приемки:**
- Форма добавления содержит поля: сумма, дата (календарь), категория (выпадающий список с учётом типа), тип (доход/расход), комментарий (опционально).
- После сохранения транзакция сразу отображается в ленте транзакций и влияет на отчёты.
- Реализованы полноценные операции CRUD для транзакций через API и интерфейс.

---

#### 5. Отчёты и аналитика

| ID | User Story | Приоритет |
|----|------------|-----------|
| US‑09 | **Как пользователь, я хочу видеть Balance Sheet (обзор текущих остатков, активов, агрегированных трат за предыдущие периоды) в виде дашборда, чтобы быстро оценить финансовое состояние.** | Must have |
| US‑10 | **Как пользователь, я хочу получать отчёт о движении денежных средств (ДДС) с группировкой по категориям за выбранный период, чтобы анализировать структуру доходов и расходов.** | Must have |
| US‑11 | **Как пользователь, я хочу просматривать простые графики (круговые диаграммы, столбчатые) по категориям расходов и доходов, чтобы наглядно видеть распределение.** | Must have |

**Реализованные критерии приемки:**
- **Дашборд (US‑09)** содержит:
  - Общий баланс (сумма всех доходов минус расходы).
  - Баланс за выбранный период (1, 3, 6, 12 месяцев).
  - Круговые диаграммы структуры доходов и расходов за выбранный период.
  - Линейный график изменения накопленного баланса с возможностью группировки по дням, месяцам и кварталам.
- **Отчёт ДДС (US‑10)** позволяет:
  - Фильтровать транзакции по дате, категории, типу.
  - Выбирать режимы группировки: без группировки, по категориям внутри дня, сводка по дням, месяцам, кварталам.
- **Графики (US‑11)** реализованы с использованием библиотеки recharts:
  - Круговые диаграммы доходов и расходов за выбранный период.
  - Линейный график динамики баланса.
